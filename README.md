## Publishing a post

1. Push the card images (`assets/cards/card-<slug>.png` 1200x630 and
   `sq-<slug>.png` 600x600) before or with the post page.
2. After the push, poll the page URL AND both image URLs until all three
   return 200. GitHub Pages serves them a minute or two apart, and X caches
   whatever its crawler sees first for about a week. A link pasted into an X
   composer before the images are live gets an imageless card that cannot be
   refreshed (learned on the Scales++ post, 7 Sep 2026).
3. Only then share the link. Keep the square card to hand to attach to the X
   post directly; it renders at the same size as an arXiv link card.
